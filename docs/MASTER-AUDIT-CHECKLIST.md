# LaunchedOps Master Audit Checklist

Every LaunchedOps site must satisfy each item below or have a documented reason it doesn't apply. This is the single source of truth for site quality.

Use `/qa` to run this checklist against a client site before delivery.

---

### 📱 MOBILE

- [ ] Mobile responsive design
- [ ] Phone number is tap-to-call
- [ ] Sticky mobile CTA bar (call + estimate pinned to bottom)
- [ ] Images optimized, loads under 3 seconds on mobile
- [ ] Navigation works on small screens
- [ ] Forms work and aren't too long on mobile
- [ ] Fonts large enough to read on a phone (min 16px body)
- [ ] Buttons large enough to tap accurately (min 44x44px)

### ⚡ SPEED & TECHNICAL

- [ ] PageSpeed 90+ (target 98+)
- [ ] All images compressed (WebP preferred)
- [ ] SSL certificate active (https://)
- [ ] No broken links or 404 errors
- [ ] XML sitemap submitted to Google
- [ ] robots.txt file present and configured
- [ ] Browser caching set up
- [ ] CSS/JS minified and bundled
- [ ] Fast hosting with good server response time
- [ ] Core Web Vitals passing (CLS, LCP, INP individually)

### 🔍 LOCAL SEO

- [ ] LocalBusiness schema markup (JSON-LD)
- [ ] FAQ schema markup
- [ ] Service schema per individual service
- [ ] City mentioned in headlines and body copy
- [ ] Location-specific service pages ("[Service] in [City]")
- [ ] NAP consistent across Google, Yelp, Facebook, website
- [ ] Meta title on every page (unique, keyword-rich)
- [ ] Meta description on every page (unique, compelling)
- [ ] H1 tag with keyword on every page
- [ ] Alt text on all images (descriptive, keyword-aware)
- [ ] Google Maps / local pack visibility supported
- [ ] Google Business Profile linked from the site
- [ ] City in page URL slugs
- [ ] Separate pages for each service area (no duplicate content)
- [ ] Canonical tags on all pages
- [ ] JSON-LD breadcrumb schema
- [ ] Aggregate rating schema (when reviews are available)
- [ ] No hreflang needed unless bilingual market (note for future)

### 🤖 AI & VOICE SEARCH READINESS

- [ ] Content written in Q&A / direct-answer format AI can extract
- [ ] FAQ sections with conversational long-tail questions
- [ ] robots.txt allows AI crawlers (ChatGPT-User, etc.)
- [ ] Speakable schema markup on key content
- [ ] Structured content that answers "who/what/where/when/how" queries
- [ ] Fresh content signals (regularly updated, not stale)

### 📣 CALLS TO ACTION

- [ ] CTA above the fold
- [ ] Single clear primary CTA (no competing buttons)
- [ ] Specific CTAs ("Get Your Free Estimate" not "Learn More")
- [ ] CTAs repeated throughout the page
- [ ] Urgency or incentive present ("Same-Day Estimates Available")
- [ ] "Free Estimate" offer clearly visible
- [ ] Phone number in the hero section
- [ ] Segmented CTAs for different visitor types where applicable

### 🏆 TRUST SIGNALS

- [ ] Google reviews displayed on site (live widget or curated)
- [ ] Star rating and review count visible
- [ ] Before/after photos
- [ ] Project gallery
- [ ] Certifications and licenses mentioned
- [ ] "Licensed & Insured" badge
- [ ] Years in business displayed
- [ ] Jobs completed stat
- [ ] Testimonials with real names and photos
- [ ] Service guarantee or warranty mentioned
- [ ] BBB, Angi, HomeAdvisor badges (where applicable)
- [ ] Owner/crew headshots (real people, not stock)
- [ ] Video testimonials (placeholder or embed-ready section)
- [ ] "As seen on" / local media mentions section (if applicable)
- [ ] Project count or "homes served" counter
- [ ] Real-time social proof indicators (optional, e.g., "3 estimates booked today")

### ♿ ACCESSIBILITY / ADA

- [ ] Color contrast meets WCAG AA (4.5:1 text, 3:1 large text)
- [ ] Keyboard navigation works (tab through all interactive elements)
- [ ] ARIA labels on interactive elements (buttons, forms, nav)
- [ ] Alt text written for screen readers (not just SEO keywords)
- [ ] Form error messages explain what went wrong and how to fix it
- [ ] Skip-to-content link for screen reader users
- [ ] Focus indicators visible on all focusable elements
- [ ] No content conveyed only by color

### 📄 CONTENT & STRUCTURE

- [ ] Individual service pages (not single-page-does-all)
- [ ] Service descriptions are detailed and specific (500+ words)
- [ ] FAQ section with real customer questions
- [ ] Service area listed clearly
- [ ] About page focuses on customer benefit, not just history
- [ ] Emergency/same-day callout (if applicable to niche)
- [ ] Pricing transparency or "free estimate" prominently offered
- [ ] No expired seasonal content
- [ ] Blog or resource content for SEO footprint
- [ ] Process section ("Here's how it works")
- [ ] "Why choose us" differentiator section
- [ ] Visual breaks — icons, images, whitespace (no walls of text)
- [ ] Timeline/duration expectations per service
- [ ] Cost guidance or price ranges (even ballpark)
- [ ] Local building code or permit references (where relevant)
- [ ] Climate/seasonal considerations mentioned
- [ ] No duplicated content across city pages
- [ ] Case studies with problem/solution/result structure
- [ ] No "Coming Soon" placeholder pages

### 📬 LEAD CAPTURE

- [ ] Contact form on homepage (not buried on separate page)
- [ ] Form is short (under 5 fields before trust is built)
- [ ] Confirmation message after form submission
- [ ] Phone number in the hero
- [ ] Text/SMS option available
- [ ] Online booking or scheduling option (or placeholder for it)
- [ ] Chat widget or instant contact option (or placeholder)
- [ ] Form actually delivers to a monitored inbox

### 🔄 POST-LEAD INFRASTRUCTURE

- [ ] Thank-you page after form submission (enables conversion tracking)
- [ ] Form confirmation sets expectations ("We'll call within 30 minutes")
- [ ] Automated instant response (email or SMS) — at minimum, site is structured to support this
- [ ] CRM integration ready (form data structured for webhook/Zapier)
- [ ] Speed-to-lead guidance documented for client
- [ ] Follow-up sequence capability (documented as upsell)
- [ ] Re-engagement drip capability (documented as upsell)

### 💰 FINANCING & PAYMENT

- [ ] Financing options mentioned (if applicable to niche — fencing, concrete, etc.)
- [ ] Accepted payment methods listed
- [ ] Deposit/payment process explained (or section ready for client input)
- [ ] Online payment capability (link or placeholder)

### 👷 HIRING & CAREERS

- [ ] Careers page or "We're Hiring" section (at minimum, placeholder ready)
- [ ] Easy application path (not just "email your resume")
- [ ] Crew photos or "day in the life" content (placeholder section)

### 🎯 AUDIENCE CLARITY

- [ ] Clear residential vs. commercial separation (if serving both)
- [ ] Homepage messaging speaks to a specific audience
- [ ] Segmented CTAs for different visitor types (if applicable)

### 📊 TRACKING & ANALYTICS

- [ ] Google Analytics (GA4) installed or ready to install
- [ ] Google Search Console setup documented
- [ ] Meta/Facebook pixel ready (placeholder in head)
- [ ] Google Ads remarketing tag ready (placeholder in head)
- [ ] Call tracking guidance documented for client
- [ ] Conversion tracking on thank-you page
- [ ] Heatmap tool recommendation documented

### 🎨 DESIGN & CREDIBILITY

- [ ] Modern, professional design (not dated)
- [ ] Real photos preferred over stock (placeholders labeled clearly)
- [ ] Consistent fonts and colors
- [ ] Professional logo (or clean text logo)
- [ ] Favicon set
- [ ] Service area map (or placeholder)
- [ ] Copyright footer shows current year (dynamic)
- [ ] No dark-on-dark readability issues
- [ ] No autoplay video
- [ ] No intrusive popups on mobile
- [ ] Custom 404 page with branding, navigation, and CTA
- [ ] Clear visual hierarchy — visitor knows where to look first
- [ ] Services prominently linked (not buried in dropdowns)
- [ ] Breadcrumb navigation on interior pages
- [ ] Footer has secondary navigation, service links, service area summary

### 🔗 OFF-SITE / ECOSYSTEM

- [ ] Google Business Profile linked from website
- [ ] Yelp, Angi, HomeAdvisor profiles linked (where they exist)
- [ ] Social media icons only link to active profiles
- [ ] Backlink strategy documented for client
- [ ] Apple Maps / Bing Places listing guidance documented

### 📱 SOCIAL & SHARING

- [ ] Open Graph tags on all pages (title, description, image)
- [ ] Twitter Card markup on all pages
- [ ] Shared links render correctly on Facebook/social (test with FB debugger)

### 🔒 LEGAL / COMPLIANCE

- [ ] Privacy policy page (linked from footer)
- [ ] Terms of service page (linked from footer)
- [ ] Cookie consent banner (at minimum, placeholder ready)
- [ ] Contractor license number displayed (placeholder for client input)
- [ ] "Do Not Sell My Information" link (California requirement)

### 🛡️ SECURITY & MAINTENANCE

- [ ] CMS/framework kept up to date
- [ ] No abandoned or outdated plugins/dependencies
- [ ] Regular backups configured (or hosting handles this)
- [ ] SSL properly configured (no mixed content warnings)
- [ ] Contact form has input validation (spam/XSS protection)
- [ ] No default admin credentials

### 🔗 OFFLINE-TO-ONLINE

- [ ] QR code linking to site (guidance for trucks, yard signs, cards)
- [ ] Unique landing pages for offline marketing (e.g., /neighbors)
- [ ] UTM tracking guidance for offline-to-online URLs
- [ ] Post-job review solicitation system (QR code on invoice, SMS link)

### 🎯 RETARGETING & REMARKETING

- [ ] Email capture for non-ready visitors (lead magnet, tips, etc.)
- [ ] Exit-intent offer or popup (tasteful, not intrusive)
- [ ] Remarketing audiences being built (Meta pixel + Google Ads tag)

### ⭐ REPUTATION & REVIEW ECOSYSTEM

- [ ] Google reviews actively solicited with a system
- [ ] Review responses visible (or guidance for client)
- [ ] Consistent review counts across platforms
- [ ] Video testimonials section (or embed-ready placeholder)

### 📋 CONTENT FRESHNESS (ONGOING)

- [ ] Blog/content updated within last 12 months
- [ ] Service descriptions reflect current offerings/pricing
- [ ] No seasonal pages promoting old offers
- [ ] Portfolio/gallery shows recent work
- [ ] Site signals "active" to AI discovery engines

## Implementation Notes for Claude Code

When updating templates, follow these conventions from CLAUDE.md:
- Tech stack: Next.js + Tailwind CSS + shadcn/ui
- Schema: JSON-LD in layout.tsx (LocalBusiness, Service, FAQ, BreadcrumbList)
- Images: WebP format, lazy loaded, with descriptive alt text
- Forms: Short (name, phone, service type, message), with honeypot spam protection
- Meta tags: Generated via `src/lib/metadata.ts`
- Schema: Generated via `src/lib/schema.ts`
- Dynamic copyright year: Use `new Date().getFullYear()` in Footer.tsx
- 404 page: Already exists at `src/app/not-found.tsx` — enhance with CTA and service links
- Open Graph: Add to metadata.ts exports
- Accessibility: Add to component-level props (aria-label, role, tabIndex)
- Privacy policy: Add route at `/privacy` with boilerplate (client customizes later)
- Thank-you page: Add route at `/thank-you` for post-form conversion tracking
- robots.txt: Ensure AI crawlers (ChatGPT-User, GPTBot, anthropic-ai, ClaudeBot) are NOT blocked
