3. WHAT'S MISSING (COSTING 22 POINTS)

Every item below is a specific, closeable gap. Organized by priority — highest-impact items first.

Technical Gaps

Critical (Fix Before First Client)

  ☐ JS rendering risk — Google may index "Your City" placeholders instead of real content. Fix: static site generation during build, or server-side rendering

  ☐ No sitemap.xml — Google has no map of your pages

  ☐ No robots.txt — no crawl directives for search engines

Important (Fix Within First Month)

  ☐ No GTM container — no conversion tracking infrastructure

  ☐ No click-to-call tracking — can't prove ROI to contractor

  ☐ Google Fonts loaded from CDN — adds ~200ms latency. Self-host instead

  ☐ Images from Unsplash CDN — not self-hosted, not WebP, not optimized

  ☐ No custom OG image — placeholder path doesn't resolve

  ☐ No favicon from client brand — using truck emoji

  ☐ No Service schema — individual services not structured for Google

  ☐ No Offer/PriceSpecification schema — pricing invisible to Google

Nice-to-Have (Month 2-3)

  ☐ No 404 page — broken links hit dead end (critical once multi-page)

  ☐ No security headers — no CSP, X-Frame-Options, HSTS

  ☐ No service worker — no offline caching for repeat visits

  ☐ No critical CSS extraction — everything loads at once

  ☐ No hreflang — no multilingual signal (relevant for Spanish-speaking markets)

  ☐ CSS not separately inlined — entire stylesheet in head blocks render

Design Gaps

High Priority

  ☐ One color scheme only — every client looks the same. Need 3-4 presets

  ☐ Stock photography — no real photos of the actual business

  ☐ Before/after is two static images — no interactive slider

  ☐ No animated counters on stats section

  ☐ Map uses generic coordinates — needs real business location

  ☐ Area pill towns are placeholder — "Nearby Town 1" through 7

Lower Priority

  ☐ No work portfolio/gallery section with real job photos

  ☐ No team/about section with owner's face and story

  ☐ Review carousel is static — no rotation or "load more"

  ☐ No video anywhere — even a 15-second clip adds trust

  ☐ No cost calculator or interactive pricing tool

  ☐ No "text us a photo for instant quote" feature

  ☐ No blog structure for future SEO growth

  ☐ No dark/light theme toggle

Content Gaps

  ☐ Generic copy — "We haul it all" could be any company in any city

  ☐ Reviews are placeholder text, not pulled from real Google reviews

  ☐ FAQ answers are generic, not specific to contractor's actual policies

  ☐ No unique selling proposition differentiating this specific contractor

  ☐ Service descriptions are one-line generic summaries

  ☐ No "About the Owner" storytelling content

  ☐ No specific neighborhood or community references

  ☐ Footer description is boilerplate

4. THE UPGRADE ROADMAP (78 → 98)

Follow this exact sequence. Do NOT skip ahead. Each tier builds on the last.

Tier 1: Score 85 — Launch-Ready

Do this before delivering to your first paying client.

  ☐ Fix JS rendering risk — hardcode client data during build instead of URL params

  ☐ Add sitemap.xml and robots.txt

  ☐ Replace placeholder area towns with real nearby cities

  ☐ Replace placeholder review text with client's real Google reviews (or realistic ones they approve)

  ☐ Set real Google Maps coordinates for client's service area

  ☐ Replace Unsplash stock photos with niche-appropriate images (even better stock)

  ☐ Add GTM container (empty, ready for future use)

  ☐ Create custom favicon from client's brand/initials

Tier 2: Score 90 — Multi-Page SEO

Add after first 3-5 clients. Biggest single SEO jump.

  ☐ Build dedicated service pages: /garage-cleanout-[city], /furniture-removal-[city]

  ☐ Build city/area pages: /junk-removal-[nearby-city]

  ☐ Each page gets unique h1, meta description, schema, and content

  ☐ Auto-generate sitemap.xml from all pages

  ☐ Add canonical URL per page

  ☐ Add internal linking between pages

  ☐ Add 404 page routing back to homepage/contact

Tier 3: Score 93 — Unique Visual Identity

Kill the "template" concern forever.

  ☐ Build 3-4 color/typography presets (dark+gold, navy+white, forest+cream, light+blue)

  ☐ Different font pairings per preset

  ☐ Light theme option

  ☐ Per-client OG image generation (business name + phone + city on branded template)

  ☐ When contractors compare sites, no two look the same

Tier 4: Score 95 — Performance Elite

Screenshot this PageSpeed score and use it in your sales pitch.

  ☐ Self-host Google Fonts — eliminate external CDN dependency

  ☐ Convert all images to optimized WebP

  ☐ Inline critical CSS

  ☐ Preload self-hosted font files and hero image

  ☐ Target: PageSpeed 98-100 on mobile (most contractor sites score 40-60)

  ☐ Add security headers (CSP, X-Frame-Options, HSTS)

  ☐ Add service worker for offline caching

Tier 5: Score 97 — Interactive Elements

Small touches that make the site feel custom-built, not templated.

  ☐ Real before/after slider (drag to compare)

  ☐ Animated cost calculator (visual truck fill → estimated price range)

  ☐ Review carousel that auto-rotates with "load more"

  ☐ Animated counters on stats section

  ☐ "Text us a photo for instant quote" feature

Tier 6: Score 99 — Backend Integration

Now you're selling a system, not a website.

  ☐ Form submissions → email + SMS notification to contractor (Twilio)

  ☐ QR review system — 4-5 stars routes to Google, 1-3 stars routes to private feedback

  ☐ Click-to-call tracking with Google forwarding numbers or UTM params

  ☐ Simple analytics dashboard contractor can check

  ☐ Monthly ROI report: "Your website generated X calls this month"

Tier 7: Score 100 — Agency-Grade Content

The final 1%. Requires client participation.

  ☐ Unique, keyword-rich copy per client (interview the contractor, write like a journalist)

  ☐ Real photos of their crew, trucks, and completed jobs

  ☐ Specific neighborhood and community references in copy

  ☐ "About the Owner" storytelling section

  ☐ Service descriptions that reflect their actual specialties and policies

  ☐ FAQ answers specific to their business, not generic

6. PER-CLIENT CUSTOMIZATION GUIDE

Everything that changes from one client build to the next.

Must Change (Every Build)

  ☐ Business name — all .business-name elements + schema + meta tags + OG tags

  ☐ Phone number — all tel: links, SMS links, schema, display text

  ☐ City name — all .city-name elements + schema + meta + alt text + breadcrumb

  ☐ Service area towns — replace "Nearby Town 1-7" with real cities

  ☐ Google Maps embed — real coordinates or Place ID

  ☐ Reviewer names — real names from their Google reviews

  ☐ Review text — real review content (or client-approved realistic copy)

  ☐ Rating + review count — match their actual Google rating

  ☐ Favicon — from their logo or custom initials

  ☐ Social media links — their actual Facebook/Instagram/Google Business

  ☐ Canonical URL — their actual domain

  ☐ OG image — custom branded image for social shares

Should Change (If Info Available)

  ☐ Hero image — niche-specific or real crew photo

  ☐ Service card images — relevant to their actual services

  ☐ Pricing ranges — their actual pricing if provided

  ☐ Business hours — their actual schedule

  ☐ Service list — remove services they don't offer, add any missing

  ☐ FAQ answers — customize to their actual policies

  ☐ Color scheme — from preset library to match their brand

  ☐ About/USP copy — anything that differentiates them

URL Parameter Reference (for demos only)

These params personalize the demo link before the client pays:

?name=Business Name

&city=City Name

&phone=10-digit phone (auto-formatted)

&r1=&r2=&r3=Reviewer names

&rating=Google rating (e.g., 4.9)

&reviews=Review count (e.g., 150)

&jobs=Jobs completed stat

Example: demo.launchedops.com/?name=Big%20Tex%20Junk&city=Arlington&phone=8175551234&rating=4.8&reviews=150

  ☐ Google Analytics or GTM installed

  ☐ Google Business Profile — link website URL

Responsiveness

  ☐ Test on Android (Chrome)

  ☐ Hero section fills viewport on all devices

  ☐ No horizontal scroll on any device

  ☐ Images don't overflow containers

SEO Validation

  ☐ Verify canonical URL points to production domain
