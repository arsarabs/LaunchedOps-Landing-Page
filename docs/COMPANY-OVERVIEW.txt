LAUNCHEDOPS — COMPANY OVERVIEW
================================

WHAT WE ARE
-----------
LaunchedOps is a website delivery service built specifically for blue-collar
contractors — junk removal, tree service, fencing, concrete, and similar
trades. We sell production-quality, SEO-optimized, single-page websites that
look and perform like $5K+ custom builds, but we deliver them in 36 hours
for a fraction of the cost.


WHAT WE SELL
------------
- One-time build fee: $999
- Monthly hosting & maintenance: $75/mo
- Each client gets: a fully custom, mobile-first, SEO-optimized website on
  their own domain with schema markup, Google review integration, and a
  QR code review automation system included as a value-add.


WHO WE SERVE
------------
Blue-collar service contractors who:
- Need a real website but don't have $3K-$10K for a traditional agency
- Are tired of cookie-cutter Wix/GoDaddy sites that don't rank
- Want something that actually generates calls/leads, not just "looks nice"
- Operate in a local service area (city + surrounding areas)

Target niches (current and planned):
- Junk removal (live — template built, first client completed)
- Tree service (planned)
- Fencing (planned)
- Concrete (planned)
- General contracting, pressure washing, landscaping, etc. (future)


HOW IT WORKS — THE PROCESS
---------------------------
1. SALES CALL (5 min callback)
   - Collect: business name, city, phone, services offered, years in
     business, crew size, brand colors/preferences
   - Pull their Google Business Profile for real reviews, rating, review count

2. BUILD (3-4 hours actual work)
   - Copy the master template for their niche
   - Swap in their brand colors (CSS variable swap)
   - Replace all placeholder content with their real info
   - Add their real Google reviews
   - Set their service areas, pricing, FAQ answers
   - Swap stock photos for client photos (or better-matching stock)
   - Update all Schema.org structured data
   - Test mobile, test links, test everything

3. DELIVER (within 36 hours of callback)
   - Send preview link to client
   - Handle revisions
   - Deploy to static hosting (Cloudflare Pages or Netlify)
   - Point their domain, set up SSL
   - Submit to Google Search Console
   - Generate QR code for their review link
   - Train client on QR review system

WHY 36 HOURS AND NOT INSTANT:
A site delivered in 20 minutes feels automated and cheap. 36 hours feels
hand-crafted and premium. The actual build is 3-4 hours — the rest is
perceived value and scheduling buffer.


THE TECH — HOW WE BUILD
-------------------------
- Pure HTML/CSS/JS — single self-contained .html file per client
- Zero dependencies, zero frameworks, zero build steps
- CSS custom properties for instant color/brand theming
- Static hosting (fast, cheap, secure, zero maintenance for clients)
- Claude Code (AI) is the build tool — we use it to personalize each site
  from the master template rapidly

Why this stack:
- Loads instantly (no JavaScript framework bloat)
- Ranks well (clean HTML, proper schema, fast load times)
- Costs almost nothing to host
- No CMS to maintain, no plugins to update, no security patches
- Each site is completely independent — one client's site can never
  break another's

THE QR REVIEW SYSTEM — OUR DIFFERENTIATOR
-------------------------------------------
Every site includes a section showcasing a QR code review automation
system. This is the value-add that separates us from competitors like
generic website builders. The contractor prints the QR code, hands it to
customers after a job, and it takes them directly to leave a Google review.
More reviews = better local rankings = more calls. It's a tangible,
physical tool the contractor can use every single day, not just a website
feature they forget about.


THE DEMO SYSTEM
----------------
Our templates support URL parameters for instant sales demos:
  ?name=Big+Tex+Junk+Hauling&city=Arlington&phone=4695550187

This lets us show a prospect "their" website during the sales call without
building anything yet. We just plug their name, city, and phone into the
URL and they see a fully functional site with their info. This closes deals.

For production (paying client) sites, all content is hardcoded directly
into the HTML — no URL params.
