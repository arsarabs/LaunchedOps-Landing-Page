LAUNCHEDOPS — FULL PROJECT STRUCTURE
=====================================

LaunchedOps is a website delivery system for blue-collar contractors. We sell
production-quality, SEO-optimized single-page websites for $999 one-time +
$75/mo hosting. Each client site is built from a niche template, personalized
with their business info, then deployed. Build time target: 3-4 hours per site.


ROOT FILES

                           Contains tech stack, niche intelligence, SEO standards,
                           conversion standards, personalization points, skills catalog.

MAGIC DEMO LINK SYSTEM
----------------------

Both templates and the Junk Moose client site support URL parameter
personalization for cold call demos.

URL format (no commas in numbers, + as %2B, spaces as %20):

  https://demo.launchedops.com/?name=Lone%20Star%20Junk%20Removal&city=Dallas&phone=4695557890&rating=4.9&reviews=215&jobs=3500%2B

Parameters:
  name      Business name
  city      City of operation
  phone     10-digit phone number
  rating    Google rating (e.g. 4.9)
  reviews   Review count (e.g. 215)
  jobs      Jobs completed (e.g. 3500%2B)
  r1/r2/r3  Reviewer names (tree service template only)

demo.launchedops.com points to the junk removal demo (Netlify, deployed from
arsarabs/sales-demo-final repo). Tree service demo is not yet deployed.
